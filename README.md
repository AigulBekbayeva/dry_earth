# Dry Earth — три карты о засухе

Интерактивный мини-геопортал для картографического челленджа: слева панель с описанием,
легендой и переключением карт, справа — карта (глобус или плоская проекция).
Интерфейс на английском.

| | Карта | Что показывает |
|---|---|---|
| 01 | **Where are the driest places on Earth?** | Годовые осадки и индекс аридности на сетке ~18 км |
| 02 | **Which regions are getting drier?** | Изменение осадков к 2041–2060 гг. (прогноз CMIP6) по 46 регионам МГЭИК |
| 03 | **Who is most vulnerable to drought?** | Пересечение частоты засух, плотности населения и занятости в сельском хозяйстве по странам |

У каждой карты есть прямая ссылка: `…/#01`, `…/#02`, `…/#03`.


## Данные и методика

### Карта 01. Самые сухие места

- **Осадки** — климатология CRU CL 2.0 (New et al., 2002): средние за 1961–1990 гг.,
  сетка 10′ (~18 км), вся суша кроме Антарктиды. Взята в упаковке проекта NicheMapR.
- **Антарктида** — в CRU CL её нет, поэтому она заполнена оценками GPCP v2.2
  (спутники + осадкомеры, 1979–2010, сетка 2,5°). Это заметно более грубые данные.
- **Индекс аридности** = осадки / потенциальная эвапотранспирация. Эвапотранспирация
  посчитана здесь по формуле Харгривса из месячных минимальных и максимальных температур
  того же набора. Классы ЮНЕП: < 0,05 гипераридная зона, 0,05–0,2 аридная,
  0,2–0,5 полуаридная, 0,5–0,65 сухая субгумидная.
- **Пустыни** — контуры Natural Earth; показано среднее по площади контура.

Ограничения: базовый период старый (1961–1990); в ячейке усреднено ~300 км², отдельные
метеостанции могут быть суше или влажнее; там, где станций мало (Гренландия, центр
Сахары, Тибет), значения интерполированы на большие расстояния.

### Карта 02. Где становится суше (прогноз до 2050 г.)

- **Данные** — региональные средние моделей CMIP6 из репозитория интерактивного атласа
  МГЭИК (IPCC WGI Atlas, Iturbide et al., 2021): месячные осадки и температура над сушей
  в 46 референтных регионах AR6, по одному прогону на модель (28–33 модели в зависимости
  от сценария).
- **Показатель** — изменение среднегодовых осадков за 2041–2060 гг. (20 лет с центром
  в 2050 г.) относительно 1995–2014 гг. в той же модели, в процентах. На карте — медиана
  по ансамблю; в подсказке — диапазон 10–90-го процентилей и число моделей с уменьшением.
- **Штриховка** — регионы, где менее 80 % моделей согласны в знаке изменения.
- **Сценарии** — SSP1-2.6, SSP2-4.5 (по умолчанию), SSP3-7.0, SSP5-8.5.
- «Осадки сегодня» в подсказке — наблюдения W5E5 за 1995–2014 гг. из того же репозитория.

Ограничения: осадки — только одна сторона сухости. Влажность почвы зависит ещё и от
испарения, которое растёт с потеплением, поэтому регион с небольшим ростом осадков
может всё равно стать суше. Регионы крупные, изменения внутри них неоднородны.

### Карта 03. Кто уязвимее всего

Три составляющие по странам:

| Составляющая | Как считается | Источник |
|---|---|---|
| Частота засух | Доля 12-месячных периодов 1979–2010 гг., когда осадки были ниже 80 % нормы; среднее по территории. Ячейки с осадками < 100 мм/год исключены | GPCP v2.2, сетка 2,5° |
| Плотность населения | Человек на км² суши, последнее доступное значение | Всемирный банк, WDI `EN.POP.DNST` |
| Зависимость от сельского хозяйства | Занятость в сельском хозяйстве, % от всех занятых (модельные оценки МОТ), последнее значение | Всемирный банк, WDI `SL.AGR.EMPL.ZS` |

Каждая составляющая переводится в процентильный ранг (0–1) среди оценённых стран.
**Итоговый индекс = 100 × (r₁ · r₂ · r₃)^(1/3)** — среднее геометрическое, поэтому высокий
балл получает только страна, у которой высоки все три показателя сразу. Белым контуром
обведены страны, входящие в верхние 40 % по каждой из трёх составляющих.

Оценено 166 стран. Не оцениваются: страны меньше 5 000 км² (сетка осадков слишком грубая)
и территории без данных Всемирного банка.

Ограничения: это индекс подверженности, а не прогноз голода. Он не учитывает орошение,
транзитные реки (например, Нил для Египта), доходы и способность страны справляться
с засухой. Период для засух — 1979–2010 гг. Средние по стране скрывают засушливые
провинции внутри больших государств. Выбор порогов (80 % нормы, 100 мм, верхние 40 %)
и равные веса составляющих — авторское решение, их легко изменить в `scripts/prep_map03.py`.

### Границы

Береговая линия и границы стран — Natural Earth 1:50 000 000. Границы показаны так, как
они даны в этом наборе, и не выражают позиции по спорным территориям.

## Как пересобрать данные

Готовые файлы уже лежат в `data/`. Чтобы получить их заново из первоисточников
(нужны `curl`, `git`, `unzip` и Python 3 с `numpy`, `Pillow`, `netCDF4`):

```bash
pip install -r scripts/requirements.txt
bash scripts/download.sh     # ~150 МБ в папку raw/ (она в .gitignore)
bash scripts/build.sh        # пересоздаёт data/
```
